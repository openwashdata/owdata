# owdata: Index of openwashdata R Data Packages

Index metapackage for the openwashdata R data packages. Ships a
harvested catalog of every package in the openwashdata GitHub
organisation, with its datasets and variables, as internal data behind
accessor and search functions, and installs any listed package from the
openwashdata R-universe. The catalog is refreshed by a weekly harvest.
